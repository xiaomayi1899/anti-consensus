# 反共识选号 v3 · 双色球 / 大乐透

一个独立的手机网页 / PWA：不猜“会开什么”，而是按走势图给每个号码逐项计算共识分，再确定性枚举组合，固定选出一注低共识号码。

- **全新网址**：<https://xiaomayi1899.github.io/anti-consensus/>
- **只做两个彩种**：双色球、大乐透
- **独立 PWA**：可添加到 iPhone 主屏幕，自动刷新，离线可看
- **不是预测**：不提高中奖概率；目标是降低“和很多人选到同一注”的概率，从而在若中奖时减少分摊

> 每一注组合的中奖概率完全相同。反共识、冷热、遗漏、连号、同尾都不是“必开信号”。仅供娱乐，理性购彩。

## 为什么做这个页面

双色球、大乐透的浮动奖奖金会按中奖注数分摊。大部分彩民会看走势图：追近期的热号、补长期未出的冷号、留上期重号、看邻号与斜连、按区间轮动和和值回归，再配上奇偶/大小/三区均衡。这些号码一旦中奖，更容易多人同时中奖。

本页换一个思路：

1. **逐号计算**：每个号码按热 10、热 30、遗漏、重号、邻号、斜连、区间、尾数逐项加权，得到固定共识分。
2. **确定性组合**：取共识分最低的 16 个号码，枚举所有合法组合，按组合得分从低到高排序，取第一注。
3. **固定一注**：不使用随机数，刷新页面/重复点击不会换号；只有新开奖数据或切换统计窗口才重算。
4. **给出解释**：每个号码的排名、各项得分、总分、是否入选，以及 14 条走势图策略。

页面会明确标出：**反共识度**、**平均共识分** 和 **组合计算得分** 只是“偏离走势图彩民共识”的程度，不是中奖概率。

## 页面能看到什么

- 最新开奖、奖池、下期开奖倒计时
- 和值走势 SVG、最近 15 期号码分布矩阵、近期形态表
- 固定一注；每个号码带“热号 / 高遗漏 / 重号 / 邻号 / 斜连 / 空档”等走势标签
- 每个号码的逐项计算明细（热10 / 热30 / 遗漏 / 重号 / 邻号 / 斜连 / 区间 / 尾数 / 共识分 / 是否入选）
- 14 条走势图策略：热号追踪、冷号回补、上期重号、邻号延伸、斜连走势、连号形态、同尾走势、区间轮动、和值回归、奇偶均衡、大小均衡、空档回补、跨度选择、热尾轮动
- 自动刷新：每 60 秒检查开奖数据；但号码固定，只有新开奖数据或切换窗口才重算

## v3 优化日志

- **v1 问题**：生日号 / 吉利号 / 尾 4 权重过高，反选看起来刻意。
- **v2 问题**：虽然改为走势图策略，但仍使用随机模拟和重新抽号，点击就换号。
- **v3 改动**：去掉随机模拟与重新抽号；每个号码单独加权计算，组合确定性枚举排序，当前数据下固定一注。
- **下一步**：根据反馈调整各走势因子的权重，持续迭代。

## iPhone 安装

1. 用 **Safari** 打开 <https://xiaomayi1899.github.io/anti-consensus/>
2. 点底部「分享」→「添加到主屏幕」
3. 以后从桌面图标打开，即为独立全屏页面

> 微信内置浏览器不支持添加到主屏幕；请用 Safari。

## 关于返奖率

双色球/大乐透官方返奖率约 **51%**（奖金约 50% + 调节基金），不是 40%。销量高不等于返奖率低；浮动奖奖金会因中奖注数增加而被分摊。反共识只能影响“撞号/分摊”，不能改变中奖概率。

## 数据来源

- 中国福利彩票官方公开接口：<https://www.cwl.gov.cn/>
- 中国体育彩票官方公开接口：<https://www.sporttery.cn/>
- GitHub Actions 海外环境无法直连官方接口时，自动回退到 500.com 公开历史页

`scripts/fetch_data.py` 在 GitHub Actions 中每 10 分钟运行一次，抓取最近开奖数据并重新部署页面；单个来源失败时保留上一次成功数据。

## 本地运行

```bash
python scripts/fetch_data.py
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

> Service Worker 需要 HTTPS 或 localhost 才会启用；局域网 http 访问时页面正常，但离线缓存不会注册。
