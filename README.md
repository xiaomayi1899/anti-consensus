# 反共识选号 · 双色球 / 大乐透

一个独立的手机网页 / PWA：不猜“会开什么”，而是先用走势图统计，再反推“彩民会怎么选”，最后刻意避开大众偏好，选一注低共识号码。

- **全新网址**：<https://xiaomayi1899.github.io/anti-consensus/>
- **只做两个彩种**：双色球、大乐透
- **独立 PWA**：可添加到 iPhone 主屏幕，自动刷新，离线可看
- **不是预测**：不提高中奖概率；目标是降低“和很多人选到同一注”的概率，从而在若中奖时减少分摊

> 每一注组合的中奖概率完全相同。反共识、冷热、遗漏、连号、同尾都不是“必开信号”。仅供娱乐，理性购彩。

## 为什么做这个页面

双色球、大乐透的浮动奖奖金会按中奖注数分摊。很多彩民会集中选择生日号、吉利号、近期热号、奇偶/大小/三区均衡的组合，这些号码一旦中奖，更容易多人同时中奖。

本页换一个思路：

1. **看走势**：近 30/100 期冷热、遗漏、和值、奇偶、大小、三区、连号、重号。
2. **模拟彩民**：用 2000 轮虚拟投注模拟生日号、吉利号、忌讳尾 4、追热、均衡偏好等心理偏差。
3. **反着选**：给每个号码和组合计算“共识度”，优先选择低共识号码，并保留连号、同尾、偏态、尾 4 等大众认为“不可能”的形态。
4. **给出解释**：最终一注、备选一注、每个号码的共识分，以及 14 条心理学/统计学反推规则。

页面会明确标出：**反共识度** 和 **模拟撞号风险** 只是“偏离大众偏好”的程度，不是中奖概率。

## 页面能看到什么

- 最新开奖、奖池、下期开奖倒计时
- 和值走势 SVG、最近 15 期号码分布矩阵、近期形态表
- 反共识一注 + 备选一注；每个号码带“非生日 / 尾 4 / 高遗漏 / 上期重号”等标签
- 每个号码的共识度排行榜
- 14 条反推规则：生日效应、吉利数字、忌讳数字、热手谬误、赌徒谬误、连号错觉、同尾规律、均衡偏好、上期重号、均匀分布、从众合买、锚定效应、小数定律、损失厌恶
- 自动刷新：每 60 秒检查开奖数据；每 5 分钟重新反推

## iPhone 安装

1. 用 **Safari** 打开 <https://xiaomayi1899.github.io/anti-consensus/>
2. 点底部「分享」→「添加到主屏幕」
3. 以后从桌面图标打开，即为独立全屏页面

> 微信内置浏览器不支持添加到主屏幕；请用 Safari。

## 关于返奖率

双色球/大乐透官方返奖率约 **51%**（奖金约 50% + 调节基金），不是 40%。销量高不等于返奖率低；浮动奖奖金会因中奖注数增加而被分摊。反共识只能影响“撞号/分摊”，不能改变中奖概率。

## 数据来源

- 中国福利彩票官方公开接口：<https://www.cwl.gov.cn/>
- 中国体育彩票官方公开接口：<https://www.sporttery.cn/>
- GitHub Actions 海外环境无法直连官方接口时，自动回退到 500.com 公开历史页

`scripts/fetch_data.py` 在 GitHub Actions 中每 10 分钟运行一次，抓取最近开奖数据并重新部署页面；单个来源失败时保留上一次成功数据。

## 本地运行

```bash
python scripts/fetch_data.py
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

> Service Worker 需要 HTTPS 或 localhost 才会启用；局域网 http 访问时页面正常，但离线缓存不会注册。
